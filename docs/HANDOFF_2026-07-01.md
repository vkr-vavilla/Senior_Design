## Business decisions made today (pricing research done, keep for context)

- **Hosted version:** users bring their own Gemini key (LLM cost → $0); STT/TTS
  were to move to Deepgram ($200 one-time credit, ~$0.25–0.30/interview after);
  Atlas free tier; **$7/mo for 10–12 interviews** is viable (~50–60% margin),
  break-even ~3 subscribers. Groq STT (current default) free tier = shared pool:
  7,200 audio-sec/hr, 2,000 req/day.
- **Local/downloadable version:** marginal cost $0/user. Strategy: local edition
  free or one-time ~$15–25; $7/mo is the hosted product. Subscription enforcement
  on a downloadable needs a license server — decided to use a merchant-of-record
  with license keys (Polar.sh or Lemon Squeezy, both ~5%+$0.50/txn, they handle
  VAT) instead of building auth. Deferred, not started.
- Qwen2.5-7B is Apache 2.0 → commercial redistribution OK with attribution.

## Tomorrow: the "Download now" page (agreed plan)

User's goal: a web page where a user clicks Download and runs the app on their PC.
Two tracks discussed — do (1) first, it ships immediately; (2) is the real Phase 2:

1. **Ship the developer edition now:** static landing page (GitHub Pages/Vercel)
   with a one-liner installer (`curl -fsSL <site>/install.sh | sh`) that checks
   Docker, clones/downloads the repo, and runs `setup_local.sh`. Zero new backend
   work — the engine is already proven on two machines. Prereq: push the branch
   to GitHub (page needs a public URL to fetch from).
2. **Phase 2 (real installer, 10x audience):** merge LoRA into base weights →
   convert to GGUF (~q4_K_M, ~4.5 GB) → serve with Ollama/llama.cpp (OpenAI-compatible,
   so `VLLM_BASE_URL` swap only) → Tauri/Electron wrapper bundling frontend+backend
   with a first-launch model-download progress bar → .exe/.dmg/.AppImage on the
   download page. The 4090 box can do the merge/quantize and quality-check.
   License keys via the merchant-of-record when payments start.
